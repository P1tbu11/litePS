## 产品

编辑器给人用，用来做 Agent 说不清或重生成不划算的位图收尾。打开、拖入、粘贴就是拿到图。宿主接入以后再做，必须走同一条「打开一张图」的逻辑。现有调用协议冻住，不随工具膨胀。

## 第一期做

图层类型只三种：栅格、组、调整图层。

组按 PS / Photopea：可嵌套；默认穿透；非穿透时隔离合成；组蒙版与图层蒙版同一套灰度；组有不透明度和混合；整组变换（子层在组局部坐标，不烤像素）。

选区：矩形、椭圆、自由套索、多边形套索、魔棒（只采样当前层）；加减交叉反选羽化；选区变蒙版。

图层蒙版按 PS 体感。剪切蒙版要做。给 Agent 导遮罩从选区或蒙版导出，不并排一套文档级红涂。

调整图层按 PS：在栈里、可剪贴、非破坏。现有图层上的亮度/对比/饱和在调整图层落地后迁走。

画笔要做。仿制、模糊作为第一期靠后批次，必须是真实现。修复、内容识别不进第一期。

## 第一期不做

智能对象。形状、填充、渐变层（第二期；模型用 `type` 扩展，拒绝未知类型）。空壳工具。假修复、假内容识别。

## 实现批次

1. 文档模型：层树、组、校验、旧工程仍能打开
2. 合成：穿透 / 隔离、组变换、组蒙版
3. 图层蒙版与剪切蒙版
4. 选区工具
5. 调整图层
6. 仿制与模糊
