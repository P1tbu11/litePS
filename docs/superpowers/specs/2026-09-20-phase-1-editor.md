# lite ps 第一期 Spec

更新：2026-09-20

## 目标

在这个编辑器里打开一张图，人能按 Photoshop / Photopea 的层、组、蒙版、选区、调整做完合成和局部修图，导出像素和 `.lightps`。给 Agent 说不清、重生成不划算的那一段，由人做完。

不是轻量 PS 平台，不是 Agent 操作器。现有 `window.__LIGHT_PS__` / iframe 冻住。宿主以后把图送进来，必须等于「在这个编辑器里打开一张图」。

## 第一期做完长什么样

- 三种层：栅格、组、调整图层。
- 组可嵌套；默认穿透；组混合不是穿透时隔离合成；组蒙版与图层蒙版同一套；组有不透明度和混合；整组变换不烤子层像素。
- 选区：矩形、椭圆、自由套索、多边形套索、魔棒（只采样当前层）；加减交叉反选羽化；选区变蒙版。
- 图层蒙版按 PS 体感。剪切蒙版可用。
- 调整图层在栈里、可剪贴、非破坏。落地后去掉图层上的亮度/对比/饱和字段。
- 画笔可用。仿制、模糊是真实现，作为第一期最后两批。
- 打开、拖入、粘贴、保存工程、导出合成图。

## 第一期不做

智能对象。形状、填充、渐变层。修复、内容识别。空壳工具。为宿主扩协议。

第二期预备：层用 `type` 扩展；不认识的类型拒绝，不丢数据、不做假层。

## 已落地

文档模型：`RasterLayer | GroupLayer`，树、校验、旧工程无 `type` 当栅格、`shape`/`fill` 拒绝。

合成：递归走层树；穿透 / 隔离 / 组变换 / 组不透明度 / 组蒙版。视口用合成后的世界坐标显示子层，写回局部坐标。可编组、解散、嵌套列表。

图层蒙版按 PS：图层旁缩略图、添加/停用/删除、黑藏白显。组也能加同一套蒙版。剪切蒙版还没做。

## 批次

1. 文档模型 — 已完成
2. 合成：穿透 / 隔离 / 组变换 / 组蒙版
3. 图层蒙版与剪切蒙版（灰度，PS 体感）
4. 选区工具
5. 调整图层
6. 仿制与模糊

## 合成规则（批次 2）

自下而上走层树。

- 栅格：按自身变换、不透明度、混合画到当前目标。
- 组 `blend === pass-through` 且不透明度 1、无蒙版、变换为单位：子层直接画到当前目标。
- 组穿透但有不透明度或组蒙版：先留下「没有这组」的底，再画子层，用蒙版和不透明度混合两张结果。
- 组混合不是穿透：子层画进透明缓冲（组是隔离祖先），套组蒙版，再按组的混合和不透明度盖回。
- 穿透只穿透到最近的隔离祖先或画布。
- 组变换乘在子层局部坐标上，不改子层字段。
- 组蒙版与图层蒙版同一表示。批次 2 先吃现有笔画蒙版；批次 3 换成灰度图后，合成只换蒙版取样，不换组规则。

## 明确会先这样、以后再换的点

1. 人用界面已去掉 Q / 重绘区域 / 导出黑白遮罩。那是早期给 Agent 涂范围用的，不是 PS。旧工程里的 `inpaint` 和协议 `export.mask` 仍能打开，人不再看见。图层蒙版按 PS 做，做在图层旁边。
2. 图层上的亮度/对比/饱和先留着，调整图层落地再迁。
3. `schemaVersion` 仍为 1，靠缺省 `type: raster` 兼容旧工程。
4. 批次 2 的组蒙版先复用 `Stroke[]`，不是最终灰度蒙版。

这四条是实现顺序，不是改产品结论。
