# Light PS

独立的轻量在线图片编辑器，用于已有专业修图工具之外的快速修改。界面参考 Compositor 的原生 Mac 风格；Photopea 是品类与成熟度参照，不是功能全量目标。

## 本轮实现范围

导入/粘贴 PNG、JPEG、WebP；多图层排序/锁定/显隐/混合；移动缩放旋转翻转；裁切；矩形选区；画笔和可恢复擦除；基础调色；独立重绘遮罩；撤销重做；本地自动恢复；可携带工程文件；图片与遮罩导出；同页 JS API 和明确授权来源的 iframe 通信。

PSD、文字排版、智能对象、账号/云素材库、本地常驻服务、MCP 与 TapNow/LightAI/Figma 专用适配属于后续范围，不作为本轮完成条件。通用接口先保持小而明确，不宣称专用集成已经实现。

## 复用决策

评估 miniPaint `a79733eb803fc97084ef0ee4faa96b031e69e1c0`：已有工具丰富，但 `base-gui` 动态初始化全部菜单模块，工具绑定全局事件，工程模型与界面单例共享；独立可恢复图层蒙版及新 UI 需要较大改造。此版使用 Fabric 7.4 的选择/变换/视口能力，不复制 miniPaint 源码；UI 用 React，工程模型和像素输出与 Fabric 序列化解耦。

运行时无图片处理服务器、登录或外部字体请求。素材在浏览器内处理；只有用户主动调用外部连接才涉及传输。浏览器恢复缓存不能替代下载工程备份。

## 启动

Node.js >= 22.12。

```sh
npm ci
npm run dev
npm run build
npm test
```

## 验收门槛

1. 两张图片导入、变换、排序、混合后，导出尺寸等于文档尺寸，与视口缩放和 DPR 无关。
2. 擦除只影响目标图层，可恢复；隐藏/锁定图层、撤销重做表现一致。
3. 工程保存再打开与当前合成像素一致；自动恢复失败不得显示已保存。
4. 重绘遮罩独立于图层蒙版，二值导出每个像素必须为不透明纯黑或纯白。
5. 非法工程/超限图片/失败的接口命令不能破坏已有工程；远程写入检查文档版本。
6. 用真实浏览器验证上述编辑流程、快捷键、导出下载与界面布局。
